# Web 与手机共享界面

`index.html` 是浏览器入口，手机外壳也加载同一页面。脚本仍按 HTML 中的顺序加载，共享现有全局对象。

| 目录 | 职责与入口 |
| --- | --- |
| `shell/` | `app.js` 组织页面启动、网关请求与模块交互；`style.css` 提供基础布局。 |
| `features/chat/` | 会话列表、消息时间线、输入与附件、权限和工作模式。 |
| `features/accounts/` | 官方账号、API 接入、额度及客户端账号管理。 |
| `features/clients/` | 应用切换、启用管理与 Claude/DeepSeek 会话界面。 |
| `features/workspace/` | 文件与下载、源码高亮、PDF/HTML 预览、Git、终端、侧边聊天、子任务和分屏工作台。 |
| `features/settings/` | `presentation.js` 管理本地外观偏好。 |
| `shared/` | 翻译、Markdown、图片查看器与共享视觉样式。 |
| `hosts/` | 浏览器、iOS/Android App 的身份和原生布局适配；不参与宽窄判断。 |
| `layouts/` | 紧凑、中等、宽屏的页面结构与工作台容器分屏判断。 |
| `client-icons/`、`vendor/` | 客户端原始图标和有许可证记录的第三方浏览器资源。 |

## 静态地址契约

`assets.json` 将现有公开地址映射到磁盘文件，例如 `/app.js` 对应 `shell/app.js`。后端仅发布 `bridge/api/assets.py` 固定白名单允许的入口，以及限定路径的字体与 PDF.js CMap 资源；清单本身不会扩大公开范围。CSS 清单可以是有序数组，后端按原顺序在内存中组合并缓存；每个公开 URL 仍只需一次请求。搬移源文件时更新清单；HTML 中的公开地址、查询版本和脚本顺序保持稳定。

桌面网关通过本地文件引用 `shared/i18n.js` 和 `features/accounts/`；这些路径还需要出现在根 `package.json` 的打包清单中。图片地址相对于页面，CSS 地址相对于公开样式 URL；不要根据脚本所在目录改写浏览器地址。

从仓库根目录运行 `npm run test:desktop`。该命令递归发现 `tests/` 和 `mobile/tests/` 下的 `*.test.js`、`*.test.cjs`、`*.test.mjs`，无需手动添加测试清单。资源映射与桌面本地引用由 `tests/frontend-assets.test.cjs` 验证；相关功能测试按实际磁盘路径读取源码。

`tests/browser/*.browser.js` 是依赖真实页面和隔离网关夹具的浏览器检查，不属于 Node 测试；需要通过对应浏览器驱动单独执行，不能将仅加载脚本视作检查通过。

运行中的网关按 `assets.json` 的修改时间和大小刷新组合资源清单，避免新主脚本已经更新、依赖模块却仍按进程启动时的旧清单遗漏。公开 URL 仍只允许固定白名单，清单不能新增任意公开路径。资源回归应覆盖“先启动服务，再改变组合成员”的顺序。

## 文件阅读模块

文件预览中的文字选区支持电脑右键直接打开引用目标选择。手机、平板和笔的长按完全交给系统选词、复制和分享，网页不拦截任何一次触屏长按，也不在选择或调整范围时弹出功能框。选好后主动点击文件栏的“引用选区”；按钮只在该文件有有效文字选区时可用，并保留点击前的完整选区。源码引用只取代码正文，Markdown 和 PDF 取当前文字选区；HTML 预览需切到源代码后引用。文件和聊天文字共用目标选择框：主会话、每个已打开的侧边聊天，以及“新建侧边聊天”。支持侧边聊天时，即使当前只开了主输入框，也提供新建入口；不支持侧边聊天且只有主输入框时直接添加。新建入口打开独立标签并保存引用草稿，再由用户创建临时会话和发送。完整路径优先使用文件接口的项目根目录；旧网关缺少该字段时，只使用当前同一主机、同一聊天提供的绝对工作目录补全。

文件引用独立保存在对应主机、会话和输入框的草稿中，以文件名标签显示；点击标签查看完整文件路径、选中文字和远端主机，详情中的“删除引用”只删除这一条引用。发送时将路径和选区展开为消息正文，合计长度沿用输入框限制；只有引用也可发送。发送失败或结果未确认时保留标签，确认成功只移除本次发送的引用，不影响后来新增的草稿。选择、添加、查看和删除引用本身不发送聊天消息。

- Markdown 文件预览支持章节链接，以及相对于当前文件或项目根目录的文件链接。其他文件在工作台标签页中打开，已打开的文件复用其标签；带章节的链接在内容加载后定位，同名标题按 `-1`、`-2` 区分。网址继续在浏览器新标签页打开；文件链接沿用当前聊天的主机、客户端及文件访问校验，不能跳出项目。聊天正文仍只允许服务端授权的文件链接。
- `source-view.js` 用本地 Prism 词元生成只读源码节点，行号独立，复制取原文；软换行与原始行宽可切换。超过 65,536 字符或 4,000 行不高亮，超过 10,000 行省略行号，仍遵守 512 KiB 文本预览上限。见[源码约定](../.agents/notes/implemented/feature/2026-10-13-source-code-view.md)。
- `pdf-preview.js` 使用随网关分发的 PDF.js legacy 模块、worker、CMap 和字体。沿用鉴权下载与 Range，并加 `preview=1`：服务端逐次检查实际大小不超过 `min(20 MiB, clickDownloadMiB)`，不能与显式下载或目录归档混用。可见页按需绘制，预算内保留至多两张邻近完成画布；缩放保留旧画布，单个离屏绘制完成后替换，文本层独立更新。已显示画布最多约 12 MP，替换缓冲另限约 4 MP；这是单个阅读器的画布预算，不是所有标签的总内存预算。
- `html-preview.js` 只把文本交给已鉴权的 `/html-preview-shell`。父页核验消息来源与壳实例；壳的 CSP 与 iframe sandbox 隔离内联脚本，不授同源、网络、表单、弹窗或导航权限。Android/iOS 原生壳仅放行预期的预览子页面，拒绝其余高权限操作。关闭或切换到源码时销毁 iframe，标签返回重新握手。见[PDF/HTML 约定](../.agents/notes/implemented/feature/2026-10-13-pdf-html-preview-and-source-mode.md)。
- `workbench.js` 持有目录返回、阅读位置和全屏状态。Back 先退出预览全屏、关闭浮层，再处理当前文件目录；文件子目录先回父级，根目录后回聊天。Markdown 全屏包含实际工作台标签栏，点击文档链接、切换文件标签、关闭当前文件后继续查看剩余文件时保持全屏；异步加载期间也保留标签栏与退出按钮。回到聊天、切换会话或主动退出时恢复原布局。全屏沿用同一预览实例，不重新创建 PDF 或 HTML。

Claude 账号面板的定时刷新只读已保存额度；只有显式 `details(refresh=True)` 查询。成功快照的日期时间与面板刷新时间分开，失败不能覆盖原成功值。见[手动额度约定](../.agents/notes/implemented/bug-fix/2026-10-12-keychain-access-and-manual-quota.md)。

## CLI 能力展示

主会话和侧边聊天输入区的原 Skill 按钮统一改为“＋”，共用“技能／项目文件／会话”引用弹窗。技能插入 `$技能名`，项目文件插入执行端的完整文件路径，Codex 会话插入与列表“复制会话路径”相同的 `codex://threads/<id>` 链接。引用直接写入输入框的光标位置，可以修改或删除，随消息正文发送；不再显示已选技能标签，也不再为新消息另附技能 ID。弹窗关闭、切换标签或聊天时取消旧查询，过期回包不能写入另一条聊天；选择会话引用不会打开或激活被引用的会话。侧边技能从对应临时子会话的目录读取，项目文件和会话引用复用主会话目录入口；每个侧边输入框各自保存弹窗状态。未创建的侧边草稿也能先插入文件或会话引用，技能在创建后可用。切换主会话、工作台标签或关闭侧边面板时关闭弹窗并取消旧读取；发送结果未确认时保留引用正文，不自动重放。

项目文件保留完整目录层级，逐级展开时按需读取目录，支持显示隐藏文件和项目内递归搜索；搜索结果保留父目录，目录与搜索各自分页。完整路径来自当前会话授权工作区的 `root`，SSH 使用远端路径，不能用本机路径替代。搜索排除 `.git`、上传临时项和链接，不跟随符号链接或 reparse point；最多扫描 20,000 项、32 层、2 秒协作式时间预算，受限或读取不完整时明确提示缩小范围，不能当作全量结果。

会话选择保留分区、项目和聊天的层级，支持搜索与分页，并沿用当前设备的分区归属设置。其他客户端复用同一弹窗；未提供原生分区时显示默认分区，未提供原生会话链接时明确提示使用当前网页的会话链接，未提供本机项目目录时显示原因。

会话模型与思考程度优先显示原生快照的最新值；缺少顶层字段时，读取同一快照中的会话设置、协作模式设置和最新轮次参数。历史读取保留该轮记录的权限策略供展示，不用全局默认值或其他轮次猜测缺失设置，也不以历史权限代替实时操作前的权限核验。

原生思考程度为空时，输入框工具栏显示“思考程度未指定”，不再隐藏。自定义权限也保留名称；“dangerFullAccess + on-request”显示“完全访问 · 请求批准”，仍作为自定义组合处理，不等同于无需批准的完全访问预设。权限详情只用于展示，不参与授权判定。

聊天区域右侧居中显示“我的消息导航”，每条已加载的用户消息对应一条细横线；鼠标悬停、键盘聚焦时在聊天区域右下角展开摘要列表，细横线位置保持不变。点击或触屏轻触横线一次即可跳转，不拦截首次点击。展开后每项至少 44px，长列表可在导航内滚动，Escape 或点击外侧收起。展开框贴着消息滚动区右下角，随输入框和窗口尺寸调整，保持在输入框上方。分页补读后同步增加横线，展开区也提供“查看更早内容”；不会为生成导航自动读取完整历史。跳转保存阅读锚点，后续流式回复不会把阅读位置拉回底部。

列表与会话快照的 `access` 字段控制 CLI 历史阅读、显式连接和允许的操作。界面不自动接入 CLI；服务端独立校验相同能力，隐藏按钮不能替代权限检查。连接失败保留原因，连接成功后清除；诊断下载使用既有登录会话。无 `access` 的旧网关维持原桌面行为。

## Codex 侧边栏

会话标题带有来源标记：原生保存名称、预览摘要、分页消息摘要和占位名称。实时快照没有正式名称时，保留已读取的正式标题，不能把当前分页的第一条消息当成正式名称覆盖侧栏；原生正式名称到达或发生重命名后仍正常同步。标题合并只作用于展示，不修改原生 IPC 快照或数据库。

会话条目的电脑右键、手机或平板长按菜单提供“标记为未读”，选择后立即显示蓝色未读圆点。标记保存在当前设备，列表和活动刷新不会清除；再次打开该会话时清除。操作只更新本地阅读状态，不启动或切换会话。

列表新增“Codex 分区”视图，新用户默认使用此视图，已有显示偏好保持不变。列表刷新时读取当前 Codex 账号的自定义分区名称、顺序、项目归属和初始折叠状态，并读取会话数据库的分区、置顶和项目字段；独立聊天不根据工作目录重新归入项目。已保存的空项目也提供新建入口。项目标题右侧的“＋”打开已选中该项目的新建窗口，沿用原有创建请求与结果未知时不自动重放的规则。创建成功立即加入列表，后台读取暂未包含新 ID 时保留已确认条目，直到正式列表接管。会话标题尚未生成时显示首条消息的简短摘要，原生标题到达后立即更新聊天头部和列表；暂缺标题的实时快照不覆盖列表已有标题，列表稍后返回标题时也会更新当前聊天头部。

项目组内支持鼠标拖动，以及长按或右键菜单的“在项目中上移／下移”。顺序保存在当前设备，按网关和完整项目键隔离；不改变原生项目归属或桌面设置。“最近”视图继续按交互时间排序，新建聊天优先显示，筛选和分页不会清掉尚未加载会话的已存顺序。

“Codex 分区”和“按项目”视图中，每个项目首次展开显示 5 条会话，点击项目底部“加载更多”后每次增加 10 条，最后不足 10 条时显示剩余会话。各项目独立记录本次页面的加载进度，后台刷新、折叠再展开和调整顺序时保留；切换筛选或退出登录后重新从 5 条开始。已有全局列表不足以提供该项目的下一页时，只读补查后续列表，直到找到足够会话或确认末尾，不受其他项目占用首批记录的影响。

列表每 15 秒自动同步标题，侧栏已滚动或手机侧栏已收起时也继续同步；网页回到前台时立即检查。新标题到达后更新当前聊天头部和侧栏，“新聊天／未命名聊天”等旧占位快照不覆盖已知标题；刷新保留滚动位置和各项目已加载条数。

运行标识每 5 秒读取父会话及其完整子代理树的汇总状态。父会话已结束本轮、任一子代理或嵌套子代理仍在运行或等待回应时，侧栏绿点提示“子代理运行中”，聊天头部同步显示；父会话暂时断开不掩盖已确认的子代理运行。子代理状态未知时显示不可用，待全部结束后才显示父会话的完成未读标识，进入会话后清除。子代理继续只出现在原会话的子智能体面板，不作为可发送的普通聊天暴露。

当前任务执行中点击发送，会先弹框选择“排队发送”或“补充当前任务”，每条新消息单独选择，不沿用上次选择。取消、返回、Escape 或点击遮罩只关闭弹框，文字、附件和 Skill 保留，不发送消息；切换聊天也取消原选择。界面状态稍有延迟、后台明确拒绝普通发送时，同样弹框，选择前不重发。已有结果未确认的请求沿用原 ID 和发送方式核对，不能因弹框改选而生成重复消息；空闲会话保持直接发送。

同一分区或置顶区内的项目，也可通过电脑右键、手机或平板长按后的“上移／下移”调整顺序，原生项目管理菜单同样保留这两个选项。各区域独立保存项目排序，使用含主机的完整项目键；置顶、移动到其他分区或返回原分区时，各区域保留自己的顺序。排序只交换同区域的项目位置，直接放在分区中的聊天保持原位；首尾越界操作禁用。普通“按项目”视图同样支持项目排序。

分区名称、结构和原生归属仍从当前 Codex 账号读取。项目标题和聊天条目都支持电脑右键、手机或平板长按弹出操作菜单，可置顶、取消置顶，或在“移动到分区…”弹出框选择已有分区、普通项目位置及“跟随 Codex”。归属覆盖按网关、主机、条目类型与 ID 保存在当前设备，刷新后继续生效；取消置顶恢复置顶前的位置，目标分区被删除时回到有效的原生归属或普通位置。移动只调整页面分组，保留聊天原项目、工作目录及执行归属。分区本身的新增、重命名和删除仍由电脑端管理。

置顶、自定义分区、项目分区和项目子列表的展开/收起在当前设备持久保存，桌面状态只提供首次默认值；刷新列表、切换聊天和重新打开页面不会覆盖本机选择，已移除节点的延迟 toggle 事件不写回偏好。无法确定当前账号时不合并多个账号的自定义分区。ChatGPT 云端聊天不属于本网关的 Codex 会话列表。

侧栏工具栏“⋯”菜单提供“折叠所有”，一次收起当前列表中的全部分区和项目，并立即保存到当前设备；列表刷新后仍保持收起，可以逐项重新展开。该操作保留项目已加载的聊天条数及当前聊天状态。

聊天头部和列表头部都有导航栏开关，选择持久保存。721px 以上可保持列表与聊天并排，窄屏采用抽屉；布局只依赖可用窗口宽度，与系统、屏幕物理分辨率和 App 宿主独立。尺寸变化保留原会话、草稿和工作台标签。

Codex 新建窗口记住模型、推理强度和权限，按网关地址、运行主机和聊天类型隔离，不使用重启即变化的登录列表缓存标识；随后在这些新聊天中显式修改模型/权限，也更新下一次新建的默认选择。创建后通过已有设置接口应用，期间阻止发送，失败或结果未确认会提示检查，不自动重放。完全访问权限每次新建都需确认。保留默认名称或留空时不调用 `thread/name/set` 固定占位标题，等待原生标题；用户手填名称仍保存。CLI 的 `thread/name/updated` 只刷新已接入会话，不启动或切换会话。

Codex 列表支持触屏长按、电脑右键，通过“复制会话路径”复制 `codex://threads/<会话ID>` 原生链接，复制时直接使用列表中的会话 ID。App 来源聊天还支持归档、取消归档和经确认的永久删除；通过所选主机官方运行时操作，并在操作前被动核验父聊天及其子智能体的实时任务状态。CLI 来源暂保留原生端的归档/删除入口。结果未知不自动重放。仅有公开摘要正文的记录显示为“思考摘要”，空记录在页面中隐藏；后续摘要到达后重新显示。

主会话消息、侧边聊天消息和文件预览的引用共用同一个目标弹框，内容与顺序一致：主会话、所有已打开的侧边聊天、新建侧边聊天。电脑右键和主动点击“选区操作”/“引用选区”都直接打开这个弹框，不再先出现“复制/添加到会话/了解更多”等中间菜单；电脑选区旁的引用按钮也进入同一目标弹框。手机、平板和笔继续保留系统复制/分享及选区手柄，网页不注册文字的长按操作，也不取消系统 contextmenu。Android 原生选词菜单仅提供添加引用草稿的扩展入口，按当前可信 WebView 的单次选区凭证进入相同目标选择；保留系统复制、全选和选区位置，不新增 JavascriptInterface。引用不会自动发送消息。

侧边聊天在同一主会话下按独立 UUID 槽位隔离，原有不带槽位的接口保留默认侧边聊天。创建凭证绑定父会话和槽位，发送、结束与设置同时核验槽位及子会话 ID；附件仍按父会话和子会话 ID 隔离。只读状态返回同一父会话的槽位列表，打开侧边面板可发现其他设备创建的侧边聊天，读取和恢复标签不会创建运行时或发送内容。创建前发起的旧读取不能覆盖新会话及草稿。

旧聊天的数据库 `project_id` 可能为空，不能据此覆盖 Codex 保存的项目归属。项目解析优先使用原生项目字段，其次读取桌面显式归属；明确列在 `projectless-thread-ids` 中的独立聊天不按目录推断项目，其余聊天保留最长工作目录匹配。

## 新建项目

侧栏工具栏的“⋯”集中提供新建项目、新建分区。项目标题或自定义分区标题支持电脑右键、触屏/笔长按约 600 毫秒打开管理菜单；滚动或移动超过阈值会取消长按，弹出后的释放不会同时展开项目。菜单项在执行前重新验证目标仍存在，内置分区不可改名或删除。

新建项目的“浏览文件夹”打开独立选择器，包含用户目录/磁盘/当前项目快捷位置、面包屑、完整路径输入、当前目录搜索，以及空目录和读取失败提示。窄屏快捷位置改为横向排列，目录列表独立滚动。浏览、取消或新建目录不会提前改写项目表单；点击“选择此文件夹”才回填完整路径，并在项目名称为空时建议使用文件夹名。

“新建文件夹”在当前目录内创建单层子目录，完成后进入该目录供选择，无需先打开关联聊天。已登录的目录浏览返回有效期 10 分钟的 `selectionId`，绑定当前登录、父目录完整路径及目录身份；`POST /api/project-directories` 接受 `{id,parent,name,selectionId,contextId?}`，只在该父目录内创建一层子目录。创建前持有防替换目录句柄并重新核验身份，拒绝系统保留名、路径穿越、符号链接/junction 和重名覆盖；过期、重启或目录被替换时须重新浏览。旧版未携带 `selectionId` 的调用继续执行原生聊天的 `list_hosts.workspaceRoots` 授权规则。

创建后以 `GET /api/project-directory-operations?id=UUID` 只读核对；回执独立保存在 `project-directory-operations.json`，不会与项目创建记录互相占用。选择目录的新请求及其回执绑定提交时的登录身份。结果未知或重启遗留请求只能核对，不自动重新提交；新建目录本身不创建原生项目或聊天，也不扩大聊天 workspace 接口的访问范围。

`GET /api/projects?metadata=1` 分别返回 `canCreateProject` 和 `canCreateDirectory`。网页只在运行中的服务明确支持目录创建时开放按钮；旧服务仍可浏览和选择已有目录，并提示重启电脑端手机网关。仅刷新网页不会重载 Python 接口。接口不存在时显示具体重启提示，若创建已提交但回执接口不可用，仍保留未知状态并只读核对，不重放写入。

Windows 本机项目支持修改名称、移动到一个原生分区/置顶/普通项目区、移除项目记录；改名保留关联目录，移除保留文件和已有聊天。自定义分区支持创建、改名、调整分区顺序和删除；删除分区保留其中项目和聊天并回到普通列表。变更经 `POST /api/sidebar-management` 提交，并通过 `GET /api/sidebar-operations` 只读轮询；回执独立保存在 `sidebar-operations.json`，不保存侧栏全集。断线或重启遗留写入按未知处理，不自动重放。

分区和项目归属经原生桌面工具管道保存。项目改名/移除没有外部工具方法，因此由受限 Windows 组件调用 Codex 自己的“编辑项目”窗口：核验应用路径、进程创建时间、同一桌面会话、原生项目 ID/名称/路径及名称唯一性，只允许名称保存和明确保留文件/聊天的“移除本地项目”确认。组件不使用开发者工具，不覆盖原生配置文件，不删除磁盘目录或聊天。操作时需保持 Codex 打开，可能短暂显示原生窗口；完成仍以原生列表及桌面持久化读回为准。远程项目暂不提供这些管理操作。

项目由 Codex 桌面端创建和保存，网页不维护第二套项目列表。Windows 通过核验进程路径、Windows 会话及项目配置的独立桌面工具管道调用 `create_project`，随后调用 `move_project_to_sidebar_section` 保存一个分区或无分区。桌面工具列表可能不公开创建方法；不能仅依据 `tools/list` 判断是否支持。原生返回、原生项目列表、原生分区和网关只读数据全部核验后才报告完成。其他系统暂不启用创建。

文件夹须在调用聊天的原生 `list_hosts.workspaceRoots` 内。优先使用当前本机桌面聊天，否则从本配置最近的桌面聊天中选择目录匹配项；不启动或切换聊天来获得权限。第一次使用目录可能弹出 Codex 原生信任确认，网页提示在电脑完成，绝不自动批准。创建项目本身可能切换桌面的当前项目。

`POST /api/projects` 返回操作回执，网页通过已认证的 `GET /api/project-operations?id=...` 等待。`.local/project-operations.json` 仅记录幂等请求和回执，不作为项目列表数据源。断线、超时、网关重启后的未知写入不自动重放；分区失败保留已创建项目并明确报告。旧网关私有 `projects.json` 保留原文件，不再注入项目列表，也不自动迁移。


## 列表筛选栏与新聊天就绪

在显示分区、项目和会话的整个列表区域左右滑动，按下拉选项顺序切换「Codex 分区 / 最近交互 / 按项目」。其他客户端沿用其自身可用的显示方式；纵向滚动、多指、输入框和按钮不触发切换。顶部筛选栏不处理滑动切换；列表区域不再通过左右滑动切换应用，应用仍通过底部图标切换。

原「已归档」位置显示「⋯」操作菜单；Codex 的「新建项目」与「已归档」集中在菜单内。归档选中时菜单显示勾选标记，底层仍沿用原筛选状态和加载逻辑。

新聊天创建后，在读取页面前最多等待约十秒的只读会话发现，仅对 404 重试；认证失败和其他错误立即报告。模型与权限分别提交、分别核验，未确认的写入不自动重放。运行时正常返回完整历史也必须校验线程身份、绝对记录路径及退出后文件存在，避免将尚未保存的空聊天报告为成功。运行时未保存时保留结果不确定的保护，不能据此自动重新创建。

聊天输入区不再显示“提醒/提醒已开”按钮。每条聊天的提醒设置入口放在点击聊天标题打开的“聊天详情”中；提醒策略、通知通道、发送与保存行为保持原有实现。
