# DeepSeek Harness 与个人开发分支的功能对应

本轮对照上游 `main` 的 `70a275b` 到个人分支 `63c79ca` 的 23 个提交。

| 个人分支新增能力 | Harness 对应实现 |
| --- | --- |
| 客户端项目列表、项目和聊天顺序 | 读取原生 Workspace 名称、顺序和 `sessionIds`，通过原生排序接口保存 |
| 项目新建、改名、移除 | 使用原生 Workspace；移除注册不删除目录或历史 |
| 浏览目录、新建文件夹 | 共用目录选择器；创建必须持有当前登录选择父目录的凭证，再核验目录身份；同名不覆盖 |
| 分区新建、改名、删除、排序、条目归属 | Harness 没有同类原生分区实体；保存到已验证接入目录的私有 `personal-state.json`，各设备共享 |
| 置顶、取消置顶、重命名、归档、取消归档 | 使用 Harness 原生接口；标记未读沿用浏览器偏好 |
| 项目分页与全部折叠 | 每项目先显示 5 条，再按 10 条展开；刷新保留各自进度和折叠偏好 |
| 新建聊天的项目、模型和思考强度 | 原生创建后只对新聊天应用明确选择；名称可留空。不选项目时使用独立持久目录并保存该选择 |
| 主/侧边“＋”引用选择器 | 共用技能、文件和聊天链接选择器，查询绑定实际主/子会话；引用作为可编辑正文发送 |
| 消息及文件选区的统一引用目标 | 支持主草稿、已有侧边草稿、新侧边草稿；保留手机原生选词、复制和分享规则 |
| 多条命名侧边聊天、跨设备发现与改名同步 | 使用原生 `sessionController.fork`，继承原模型、权限、历史和工作目录；槽位、发送回执、技能和图片范围相互独立 |
| 侧边模型、权限、审批、停止和排队撤回 | 操作实际 Harness 子会话，只提供原生支持的选项 |
| 首条消息后台摘要 | 主聊天优先使用 Harness 原生命名；继承了旧标题的侧边分叉在首条独立消息后生成简短中文标题。缺少原生标题服务的主聊天也可使用兼容摘要；不兼容时保留预览 |
| 子智能体记录及父聊天状态 | 只读遍历原生父子关系，包括孙级任务；运行中或未知子任务抑制父聊天提前完成。独立侧边分叉不计入原任务 |
| 运行中发送选择 | 区分排队与补充；取消不发送；结果未知时保留原请求 ID、发送方式和草稿 |
| 历史回复模型与思考强度 | 只提取对应历史请求的展示字段，不用当前设置覆盖历史，不向网页返回原始请求头或凭据 |

文件预览、Git、终端、上传下载、通知详情和自适应分屏继续使用共享组件。本轮同时修复 Windows 共享命令终端在程序路径含空格时的引号错误；SSH 注入模块仍只依赖标准库，可独立执行。

## 生命周期和安全边界

接入协议为 revision 5；revision 3、4 的完整生命周期状态仍可证明安全重启，升级识别保留上一版 revision 4 源文件的 LF/CRLF 摘要。安装、令牌、账号和配置沿用已有来源核验，不自动重启运行中的接入。

读取、通知和跨设备发现不创建或激活智能体。显式分叉、发送、归档、改名和项目/分区写入均先保存网关回执；超时或结果未知不自动重放。父会话、子会话、槽位必须匹配。

Harness 分叉是原生持久聊天，与 Codex 临时侧边聊天不同：重启网关后可以继续发现；明确结束时停止并归档，原生历史保留。页面对此使用单独说明。Codex 的 Goal、Fast 和账号协议仍按各客户端实际能力提供。

自定义摘要最多取首条独立文字的 2000 字符，不读取附件、项目文件，不给父聊天追加消息。调用同一 Harness 提供方和模型，选择支持的最低思考强度，禁用工具，30 秒超时；同时只执行一个，最多排队 32 个。每条只提交一次，人工命名优先，模型变化或接入销毁会取消或放弃写回；未知任务重启后不重发。摘要消耗原模型接入的额度；提供方自身网络重试和主聊天原生命名由 Harness 控制。

新接口沿用登录、精确同源和 CSRF。侧边聊天和文件夹管理要求密码保护；内部 `side-read` / `side-write` 不直接暴露为 HTTP 接口。中继仅增加明确的 DeepSeek 路径，工作区文件边界保持不变。

## 验证

```sh
python -B scripts/test-backend.py --source-only
npm run test:desktop
node scripts/test-deepseek-browser.cjs
```

浏览器入口需要已有 Playwright 和 Chromium，可用 `NODE_PATH` 指向测试运行时。它在 1280×900、390×844、820×1180、844×390 分别执行 32 项实际 DOM 断言，覆盖第二设备发现、子会话路由、引用/草稿隔离、目录选择、分页、取消和未知请求重试。`--screenshots` 仅把合成截图写到不提交的 `.tmp/`。协议检查在 `tests/deepseek-personal.test.mjs`，HTTP、回执和目录凭证检查在 `tests/test_deepseek_personal.py`。

本轮使用合成客户端和模型，不构建或安装应用，不使用真实账号执行付费任务。源码、浏览器回归和原生客户端实机联调分别记录，不互相替代。
