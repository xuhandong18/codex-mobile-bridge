# Windows ChatGPT 分区与完整聊天操作接入

本计划来自用户于 2026-10-29 明确批准的实施方案。先验证原桌面的受限连接器，真实运行门槛通过后才扩展聊天操作与界面。

## 固定目标

- Windows 首版；保留原桌面、原账号及原聊天，不修改安装包或隔离策略。
- 固定 ChatGPT 分区位于现有“聊天”分区正上方，不增加客户端或模式开关。
- 普通 Chat 新建、发送、停止、编辑、重新生成、独立分支、附件、模型及思考设置。
- 被动读取不得导航桌面；写入未知不得自动重放；版本未知必须停用未验证能力。

## 实施顺序与门槛

1. **受限连接器**：安装指纹、Windows 身份及调试端点核验、固定只读探针、参数保留启动、断线清理。真实验证原窗口 scope、非凭据账号身份、后台读取和断线后桌面仍运行。
2. **核心聊天链路**：读取刷新、原生草稿与正式 ID 映射、发送确认、针对本轮的停止及操作回执。
3. **扩展动作**：模型/思考、文件上传处理、编辑、重新生成及原生独立分支，逐项读回验证。
4. **共享界面**：固定分区、能力驱动的输入区和菜单、草稿与未读状态；完成后端、Node、浏览器和 Windows 实机回归。

第 1 阶段真实运行门槛未通过时，不提前扩展第 2–4 阶段。自动初始化不得在任务运行或任务状态未知时重启桌面；允许提供显式的、仅在桌面已退出时运行的启动验证入口。
